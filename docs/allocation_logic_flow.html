OptiFlow Business Logic

High-Level Process Flow & Allocation Rules
📊
1. Data Ingestion & Setup
Load master datasets and establish strict Store Grade priority rankings.
Planogram (Capacities)
Stock Data (Live SOH)
Sales History
Priority: A++ > A+ > A > B+ > B > C
⚖️
2. Calculate Capacity & Deficits
Determine exactly how many units each store needs for each Brand/Commodity.
Target = Facing + Depth
Net Deficit = Target - Store SOH
If Deficit ≤ 0 ➔ Skip (Target Met)
🎯
3. Identify Target Demand (Reference SKU)
Find the "perfect" item to allocate based on local store demand.
1st Choice: Top Selling SKU (Lookback Window)
2nd Choice: Existing Store Inventory
3rd Choice: Brand Baseline
🚧
4. Apply Hard Retail Constraints
Filter warehouse candidates. A candidate SKU is REJECTED if it violates these rules:
❌ Max 3 Colors per Model
❌ Max 2 Units of Same SKU
❌ Must Keep ≥ 85% Brand SKU Uniqueness
🟢 EXACT Match
Candidate SKU exactly matches historical store inventory.
+100 Points
🔵 SIMILAR Match
High attribute similarity (Shape, Material, Color) and MRP is within ±20%.
🟡 SUBSTITUTE Match
Same brand & commodity, but MRP variance exceeds 20% limit.
-50 Points Penalty
📦
5. FIFO Dispatch Allocation
Finalize allocation by depleting warehouse inventory using FIFO (oldest stock leaves first).
Sort by Stock Age (Days)
Assign Barcode
Generate Dispatch Order
