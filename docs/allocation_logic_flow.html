(Distribution Day) Allocation Pipeline

1. Rank Stores by Priority

Sort stores by Grade (A++ ➔ C) and inner Grade lists specified by client.

2. Calculate Capacity & Deficits

Deficit = Target (Facing + Depth) - Live Store SOH (per Brand/Commodity).

Is Deficit > 0?

YES

3. Validation Gate (Verify Constraints)

Before allocating any SKU, verify limits: Max 3 Colors/Model, Max 2 Units/SKU, Min 85% Brand Uniqueness.

4. Tier 1: Recent Sales Match (Last X Days)

Find exact SKUs sold in Last X Days (configured in UI). Allocate exact match if in warehouse stock.

Is Deficit Filled?

NO

5. Tier 2: Historical Sales Match (Last 6 Months)

Find exact SKUs sold in Last 6 Months. Allocate exact match if in warehouse stock.

Is Deficit Filled?

NO

6. Tier 3: Substitute Cascade

Keep same Brand/Commodity & MRP ±20%. Relax attributes in order: Color ➔ Material ➔ Shape.

7. FIFO Batch Selection

Prioritize older warehouse stock batches (highest age in days) for the allocated SKUs.

Generate Dispatch Order

Final Outputs locked for distribution
