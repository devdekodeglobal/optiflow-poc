Store Category & Grade Prioritization Hierarchy
Applies user-defined store tier sequence (e.g. A++ ➔ A+ ➔ A ➔ B+ ➔ B ➔ C). Each store row is assigned a strict priority rank (_rank). Higher priority stores receive first claim on available warehouse inventory.
Priority Sort: A++ ➔ C Filter: Active Categories Only
↓
3
Net Deficit & Capacity Gap Calculation
Calculates physical target capacity and net deficit per store brand commodity combination:
Target Capacity = Display Facing + Reserve Depth
Net Deficit = Target Capacity - Live Store SOH
If Deficit ≤ 0, target is met (marked as EXACT match with 0 allocation required).
Target = Facing + Depth Deficit = Target - Store SOH
↓
4
Demand-Based Reference SKU Selection
Determines target attribute baseline for candidate evaluation:
1. Primary Choice: Top selling SKU in that store/brand/commodity over selected lookback window (7, 30, 90 days, or All Time).
2. First Fallback: Existing store inventory SKU.
3. Final Fallback: Generic brand baseline.
Lookback Filter (7d / 30d / 90d / All Time) Top Sales SKU Extraction
↓
5
Hard Business Constraints & Uniqueness Filtering
Evaluates warehouse candidate SKUs against 3 strict retail rules:
• 🎨 Max 3 Colors Per Model: Max 3 color variants per model per store.
• 🔢 Max 2 Units Per SKU: Max 2 physical units of the exact same SKU per store.
• ✨ 85% Brand SKU Uniqueness Rule: (Unique SKUs / Total Allocated) ≥ 0.85 to prevent SKU over-clustering.
Max 3 Colors / Model Max 2 Units / SKU ≥ 85% Brand Uniqueness
↓
6
Attribute-Similarity Cascade & Price Band Check
Computes weighted attribute match score (0 to 100) + price protection check:
Score = Shape(30) + Material(25) + FrameType(20) + Color(15) + Gender(10)
• If candidate MRP exceeds 20% price band from target MRP, subtract 50 points (triggers SUBSTITUTE).
• If candidate matches store historical SKU, add +100 points (triggers EXACT).
Score Weights: 30-25-20-15-10 20% MRP Price Protection
↓
7
FIFO Warehouse Inventory Depletion & Dispatch Order Generation
Depletes warehouse inventory using FIFO (First In First Out) based on stock_age_in_days. Assigns exact barcode and batch quantity to line-item dispatch orders.
FIFO Age Sorting Barcode Level Allocation Dispatch Order Generation
🎯 Match Type Classification Matrix

Every allocation gap is evaluated through the engine cascade and categorized into 1 of 4 match types based on physical availability, attribute similarity, and price band compliance.

Match Type Trigger Criteria & Rules Price Band Status System Reasoning Log
EXACT Candidate SKU matches the store's exact historical SKU or target SOH is already satisfied. Matches Baseline "Exact SKU matching store historical stock" or "Target met by existing SOH"
SIMILAR Candidate matches Brand & Commodity, satisfies hard constraints, and passes similarity scoring. Within ±20% MRP Band "Similar item: Same Brand, shape (CatEye), material (Acetate)"
SUBSTITUTE Candidate matches Brand & Commodity, but MRP exceeds the 20% price variance threshold from target. Exceeds 20% MRP Band "Substitute: same brand fallback (price band exceeded)"
UNRESOLVED Warehouse inventory exhausted, or candidate rejected due to Hard Constraints (Color/Uniqueness/Max units). N/A "No stock available in Corporate Office"
